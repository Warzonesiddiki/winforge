### The 3 remaining "gaps" are deliberate safety exclusions

| Web tweak | Reason it is NOT in the engine catalog |
|---|---|
| `perf-pagefile` | `PagingFiles` is a REG_MULTI_SZ value; writing a plain string/dword would corrupt the pagefile configuration. Needs a dedicated multi-sz operation before it can ship. |
| `ui-classic-context` | Operates on a registry key's `(Default)` value; the engine registry layer (Win32 `RegSetValueExW` with an empty-name pointer) does not support default-value writes. |
| `exp-classic-paint` | The web op is a narrative ("Appx: revert Microsoft.Paint …"); Appx lifecycle is handled natively by the engine's bloatware catalog instead. |

### Mapping rules (all mechanical, documented in tools/web_catalog_to_engine.py)

- `HKCU\path: Name = 0x…/n` → `registry_set_dword` · `Name = "text"` → `registry_set_string`
- undo `= default` → `registry_delete` (restores the Windows default)
- abbreviated paths (`…`) expanded only via a documented map (Explorer\Advanced, SearchSettings, PrefetchParameters)
- `powercfg`/`bcdedit`/`fsutil` → `command`; `Disable/Enable-MMAgent` → PowerShell wrapper; WMI `SetTcpipNetbios` → Get-CimInstance translation
- `Service A, B -> Mode` → one `service_start_mode` op per service; `Automatic (Delayed)` → `auto`
- `Scheduled Task: path -> Disabled/Enabled` → `task_disable`/`task_enable`
- risk `expert` → `high` (engine has no expert tier)
